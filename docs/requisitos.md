# Requisitos

## Requisitos funcionais

- Permitir a atualização em massa de preços.
- Permitir a atualização em massa de estoque.
- Permitir a atualização em massa de medidas.
- Permitir a atualização em massa de dados SEO.
- Permitir a atualização em massa de dados fiscais.
- Gerar views SQL que possam ser importadas no Excel.

## Requisitos não funcionais

- Suporte a MySQL / MariaDB.
- Compatibilidade com Microsoft Excel.
- Estrutura modular para múltiplas lojas Tray.
- Documentação clara de implantação e uso.

## Requisitos técnicos

- Banco de dados MySQL/MariaDB.
- Conexão ODBC ou Power Query para Excel.
- Arquivos CSV exportados pela Tray.
- Scripts SQL para criação de tabelas e views.
