# Contributing

Thank you for your interest in contributing to Tray Product Manager.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your contribution.
3. Open a pull request with a clear description of your changes.

## Documentation Contributions

- Improve or expand the documentation files under `database/docs/`.
- Keep content clear, concise, and aligned with the project purpose.

## Reporting Issues

- Use GitHub issues to report bugs or request enhancements.
- Include steps to reproduce and screenshots when helpful.
